# PawDone

Pet care schedules with photo proof, shared with family and helpers. iPhone app (SwiftUI) with a Supabase backend.

- Product spec: [docs/PRODUCT_SPEC.md](docs/PRODUCT_SPEC.md)
- App icon and logo: [design/](design)

```
ios/        SwiftUI app (project generated by XcodeGen from ios/project.yml)
supabase/   Database migrations and schema tests
docs/       Product spec
design/     Icon and logo source files
```

## Workflow

- Day-to-day work happens on `dev`. Pull requests go from `dev` into `main`.
- Merging into `main` deploys new database migrations: the Supabase GitHub integration applies anything new in `supabase/migrations`.

## Run the app

1. Generate the Xcode project (needed after editing `ios/project.yml`; new Swift files are picked up automatically):
   ```bash
   cd ios && xcodegen
   ```
2. Open `ios/PawDone.xcodeproj` and run the **PawDone** scheme.

Without Supabase details the app runs, but sign-in is disabled.

**Demo mode:** Sign in with Apple is unreliable in the simulator. To try the app there without signing in, add `-PawDoneDemo` under **Product → Scheme → Edit Scheme → Run → Arguments**. It uses in-memory sample data and no server. Debug builds only.

## Connect Supabase

1. Create a project at [supabase.com](https://supabase.com).
2. Turn on pg_cron: **Integrations → Cron**.
3. Apply the migrations in `supabase/migrations`, in filename order. Either paste each file into the **SQL Editor**, or use the CLI:
   ```bash
   brew install supabase/tap/supabase
   supabase init
   supabase login
   supabase link --project-ref YOUR_PROJECT_REF
   supabase db push
   ```
4. Turn on Apple sign-in: **Authentication → Sign In / Providers → Apple**. Enable it and add `com.abhaysingh.pawdone` under **Client IDs**.
5. Copy `ios/Config/Secrets.example.xcconfig` to `ios/Config/Secrets.xcconfig` and fill in the project host and anon key from **Project Settings → API**. This file isn't committed.

## Push notifications

Reminders and "task done" alerts are sent by the `send-push` Edge Function, which pg_cron calls every minute. One-time setup:

1. **APNs key:** in [Certificates, Identifiers & Profiles → Keys](https://developer.apple.com/account/resources/authkeys/list), create a key with **Apple Push Notifications service (APNs)** enabled for Sandbox and Production. Download the `.p8` file (Apple only lets you download it once) and note its **Key ID**.
2. **Function secrets:** in Supabase, go to **Edge Functions → Secrets** and add:
   - `APNS_KEY_ID`: the Key ID
   - `APNS_TEAM_ID`: `LS942W7YC2`
   - `APNS_PRIVATE_KEY`: the whole contents of the `.p8` file
3. **Vault secrets for the cron job:** run in the **SQL Editor**, with your own values:
   ```sql
   select vault.create_secret('https://YOUR-PROJECT-REF.supabase.co', 'project_url');
   select vault.create_secret('YOUR-ANON-KEY', 'anon_key');
   ```
4. Merge into `main`. The GitHub integration applies the migrations and deploys the function declared in `supabase/config.toml`.

Check it's running in **Edge Functions → send-push → Logs**: there should be a run every minute.

## Google sign-in

Optional: the button only appears once the client IDs are set.

1. In [Google Cloud Console → APIs & Services → Credentials](https://console.cloud.google.com/apis/credentials), configure the OAuth consent screen, then create two **OAuth client IDs**:
   - **iOS**, with bundle ID `com.abhaysingh.pawdone`. Note its **Client ID** and **iOS URL scheme**.
   - **Web application** (Supabase checks tokens against it). Note its **Client ID**.
2. In Supabase, go to **Authentication → Sign In / Providers → Google**: enable it, put both client IDs under **Client IDs** (web first, comma-separated), and turn on **Skip nonce check**.
3. Add the three values to `ios/Config/Secrets.xcconfig` (see `Secrets.example.xcconfig`).

## Households and testing Premium

Helpers join with an 8-character invite code from the owner's **Account → Family & helpers**. Inviting needs Premium. Until payments are built, give a test account Premium in the **SQL Editor**:

```sql
insert into public.entitlements (user_id, is_premium, expires_at)
select id, true, now() + interval '1 year' from auth.users where email = 'you@example.com'
on conflict (user_id) do update set is_premium = true, expires_at = excluded.expires_at;
```

Sign in with Apple accounts that hide their email have an `@privaterelay.appleid.com` address; find it under **Authentication → Users**.

## Sign in with Apple

This needs an Apple Developer Program membership. In Xcode, open **PawDone target → Signing & Capabilities**, pick your team, and keep the Sign in with Apple capability. To test in the simulator, sign in to an Apple Account in the simulator's Settings app first.

## Tests

- **Database:** `supabase/tests/run.sh` runs the migrations and behaviour tests against a throwaway Postgres in Docker.
- **Push sending:** `node --test supabase/tests/` tests the APNs signing and request code.
- **App:** press ⌘U in Xcode, or:
  ```bash
  cd ios && xcodebuild test -project PawDone.xcodeproj -scheme PawDone -destination 'platform=iOS Simulator,name=iPhone 17'
  ```
